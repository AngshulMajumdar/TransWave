# Results

- `transwave_results.csv` contains genuine held-out causal byte NLL, PPL and BPB for the four TransWave runs.
- `baseline_results.csv` contains the reported values from Mamba-2, Hyena, RetNet and TransWave. The older baselines use the earlier tokenized baseline protocol, so raw NLL/PPL should not be interpreted as tokenizer-independent units.
- `native_token_counts.csv` contains the completed native-token stream sizes for LLaMA-3.2, Gemma-2 and Qwen2.5 on all four corpora.
